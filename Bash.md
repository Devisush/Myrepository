## Bash

Очистить историю:
```shell  
clear
```

Получить историю:
```shell
history
```

Перелистывание, раннее введенных команд:
`Стрелка вверх/Стрелка вниз`

Выполнить последнюю (из списка history) команду:
```shell
!!
```

Выполнить указанную команду из списка (где `45` - порядковый номер из history):
```shell
!45
```

### Файловые операции

Получить структуру каталогов и файлов:
```shell
tree
```
Получить абсолютный путь к текущему каталогу:
```shell
pwd
```

Показать содержимое текущего каталога:
```shell
ls
```
или подробно:
```
ll -all
```

Посмотреть каталог (где `Dir_name` - имя нужной папки):
```shell
ls Dir_name
```

Правила использования каталога и фалов:
1. Только по-английски
1. Без пробелов и спец. символов
1. Если имя файла или каталога состоит из нескольких англ. слов, то имя можно создать так: `firstAall` или `first_a_all`
1. В имени файлов лучше всегда указывать расширение `fileName.txt`

Выйти из текущей папки:
```shell
cd ..
```
