## Bash

Очистить историю:
```shell  
clear
```

Получить историю:
```shell
history
```

Перелистывание, раннее введенных команд:
`Стрелка вверх/Стрелка вниз`

Выполнить последнюю (из списка history) команду:
```shell
!!
```

Выполнить указанную команду из списка (где `45` - порядковый номер из history):
```shell
!45
```

### Файловые операции

Получить структуру каталогов и файлов:
```shell
tree
```
Получить абсолютный путь к текущему каталогу:
```shell
pwd
```

Показать содержимое текущего каталога:
```shell
ls
```
или подробно:
```
ll -all
```

Посмотреть каталог (где `Dir_name` - имя нужной папки):
```shell
ls Dir_name
```

### Правила использования каталогов и файлов:
1. Только по-английски
1. Без пробелов и спец. символов
1. Если имя файла или каталога состоит из нескольких англ. слов, то имя можно создать так: `firstOfAll` или `first_of_all`
1. В имени файлов лучше всегда указывать расширение `fileName.txt`

Выйти из текущей папки:
```shell
cd ..
```

Вернуться в предыдущую папку:
```shell
cd -
```

Зайти в указанную папку (где `TargetFolder` - нужная папка):
```shell
cd TargetFolder
```

### Знаки:

`\` - обратный слэш

`/` - обратный слэш

`|` - вертикальный слэш

Windows: `\` - корневой каталог

Unix/Linux/Android/MacOS/iOS/BSD: `/` - корневой каталог

Выйти из текущего каталога на 2 шага вверх:
```shell
cd ..//..
```
