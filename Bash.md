## Bash

Очистить:
`clear`

Получить историю:
```shell
history
```

Перелистывание, раннее введенных команд:
`Стрелка вверх/Стрелка вниз`

Выполнить последнюю (из списка history) команду:
```shell
!!
```

Выполнить указанную команду из списка (где `45` - порядковый номер из history):
```shell
!45
```
