# Основы Git

## Зачем Git?

### Почему не флешка?

1. Флешка - потенциальный разносчик вирусов
1. Ваши личные данные могут случайно попасть на чужой компьютер
1. Антивирус может удалить ваши файлы с флешки
1. Флешка может потеряться или сломаться

### Почему не Yandex или Google Disk?

1. Облако Yandex или Google не контролирует версии файла
1. Ваши даныне к Yandex или Google могут случайно остаться на чужом компьютере


## Преимущества Git

1. Трудно потерять свои проекты
1. Легко отслеживать версии ваших проектов
1. Легко делиться с другими людьми вашими проектами
1. Легко вести совместную работу над одним проектом
1. Git - де-факто стандард, интегрирован почти во все современные технологии в IT (например в VS Code, и т.д.)
1. В Git можно создавать веб-страницы как на хостинге
1. Git-сервисы дают возможность автоматизировать сборки и тестирование ваших приложений

## Основные состояние Git-репозитория

1. **Инициализация** - `git status` - показывает текущее состояние репозитория
1. **Подготовка** - `git add .` - подготовка (добавление) изменений
1. **Фиксация** - `git commit -m "Message"`
1. **Синхронизация** - `git push` и `git pull` работа с удаленной (далекой) копией текущего репозитория

## Что можно сохранять в git?

1. Любые текстовые файлы < ~40mb
1. Изображение, документы, mp3, PDF, короткие видео и т.п.
1. Все имена файлов и каталогов только по-английски и символов

## Основные команды Git:

Получить версию установленного Git:
```shell
git version
```
или
```shell
git --version
```

Получить справку
```shell
git help
```
или
```shell
git --help
```

**Сменить текстовый едактор по умолчанию**
На `Micro` (проще для новичков)
```shell
git config --global core.editor "micro"
```
На `Nano` (чуть сложней для новичков)
```shell
git config --global core.editor "nano"
```
На `VS Code` (элементарен для новичков)
```shell
git config --global core.editor "code --wait"
```

**Представиться систему Git**
Сообщить свой никнейм:
```shell
git config --global user.name "username"
```
Сообщить свой email:
```shell
git config --global user.email "my_email@gmail.com"
```

> **Если вы на чужом компьютере, то вместо '--global' используйте '--local'**

### Клонирование репозитория

```shell
git clone https://github.com/Username/Repository #ссылка на репозиторий
```
Открыть папку клонированного репозитория:
```shell
cd folder_name
```
Получить статус текущего репозитория:
```shell
git status
```
Получить состояние удаленного репозитория:
```shell
git remote show origin
```
Получить локальные ветки текущего репозитория:
```shell
git branch
```
Получить список удаленных веток
```shell
git remote --v
```
Получить общий лог:
```shell
git log
```
Получить лог изменений с указанием колчества последних комитов:
```shell
git log -p
```

Выйти из режима логов: `Q`
