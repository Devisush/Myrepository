## Bash

Поменять директорию:
```shell
cd <путь>
```

Очистить историю:
```shell  
clear
```

Получить историю:
```shell
history
```

Перелистывание, раннее введенных команд:
`Стрелка вверх/Стрелка вниз`

Выполнить последнюю (из списка history) команду:
```shell
!!
```

Выполнить указанную команду из списка (где `45` - порядковый номер из history):
```shell
!45
```

### Файловые операции

Получить структуру каталогов и файлов:
```shell
tree
```
Получить абсолютный путь к текущему каталогу:
```shell
pwd
```

Показать содержимое текущего каталога:
```shell
ls
```
или подробно:
```
ll -all
```

Посмотреть каталог (где `Dir_name` - имя нужной папки):
```shell
ls Dir_name
```

### Правила использования каталогов и файлов:
1. Только по-английски
1. Без пробелов и спец. символов
1. Если имя файла или каталога состоит из нескольких англ. слов, то имя можно создать так: `firstOfAll` или `first_of_all`
1. В имени файлов лучше всегда указывать расширение `fileName.txt`

Выйти из текущей папки:
```shell
cd ..
```

Вернуться в предыдущую папку:
```shell
cd -
```

Зайти в указанную папку (где `TargetFolder` - нужная папка):
```shell
cd TargetFolder
```

### Знаки:

`\` - обратный слэш

`/` - обратный слэш

`|` - вертикальный слэш

Windows: `\` - корневой каталог

Unix/Linux/Android/MacOS/iOS/BSD: `/` - корневой каталог

Выйти из текущего каталога на 2 шага вверх:
```shell
cd ..//..
```

### Создание файлов и каталогов

Создание файлов:
```shell
touch file_name.txt
```

Редактировать текстовый файл:
```shell
micro file_name.txt
```
- `micro` - текстовый редактор командной строки
- сохранить через `Ctrl+S` и выйти из редактора `Ctrl+Q`

Переименовать файл:
```shell
mw old_name new_name
```

Копирование файла:
```shell
cp file_name.txt new_folder/
```

Переместить файл:
```shell
mv file_name.txt new_folder/
```

Удалить файл:
```shell
rm file_name.txt
```

Удалить папку:
```shell
rm -rf folder
```

Удалить содержимое текущего каталога:
```shell
rm -rf *
```

Создать несколько файлов:
```shell
touch {1..3}.txt
```

Создать несколько каталогов:
```shell
mkdir folderName(1..4)
```

Создать структуру проекта:
```shell
project/
├── css/
├── js/
├── img/
│   └── ico/
├── fonts/
└── pages/
```

## Linux

Имя компьютера:
```shell
hostname
```

Локальный ip:
```
hostname -i
```

Сетевая информация:
```shell
ifconfig
```
или подробно:
```shell
ip -c a
```

Пинг:
```shell
ping ya.ru
```
или определенное кол-во раз:
```shell
ping -c 4 ya.ru
```

Получить информацию по домену:
```shell
whois ozon.ru
```

Получить порты:
```shell
netstat -an
```

Получить маршруты:
```shell
route
```

Выйти из сеанса пользователя:
```shell
exit
```

Перезагрузить:
```shell
reboot
```

Выключить:
```shell
poweroff
```

Получить текущее время:
```shell
date
```

Календарь:
```shell
cal
```
или (`2027` - год)
```shell
cal 2027
```

Получить общую информацию по системе:
```shell
fastfetch
```

Получить подробную информацию по системе:
```shell
inxi -F
```
