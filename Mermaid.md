# Mermaid

**Mermaid** - это сильно упрощенный и далекий аналог UML - язык описания блок-схем, граффиков и диаграм с их визуализацией

> [x] **Самостоятельно доделать этот документ**

## Блок-схемы:

### Базовая структура 1

```mermaid
flowchart LR
    A["Вопрос: Как сделать список?"] --> B["Ответ: `-` или `*`"]
    A --> C["Пример: \n - Пункт 1 \n"]
```


### Базовая структура 2

```mermaid
flowchart TD
    A["Вопрос: Как сделать список?"] --> B["Ответ: `-` или `*`"]
    A --> C["Пример: \n - Пункт 1 \n"]
```

### Полный синтаксис блок-схем
- `flowchart` - блок-схема

#### Направления

- `LR` - направление вправо
- `LL` - направление влево
- `TD` - направление вних
- `BT` - направление вверх

#### Формы

- `A[]` - прямоугольник
- `B()` - скругленный прямоугольний
- `C(())` - круг
- `D{}` - ромб
- `E{{}}` - шестиугольник
- `F>]` - флаг

#### Стрелки

- `-->` - стрелка связи
- `---` - линия без стрелки
- `-.->` - пунктирная стрелка
- `-.-` - пунктирная линия
- `==>` - толстая стрелка
- `===` - толстая линия
- `-- Текст -->` - стрелка с текстом

### Диаграмма последовательности

```mermaid
sequenceDiagram
    autonumber
    actor Пользователь
    participant Клиент as Фронтенд
    participant Сервер as Бэкенд
    participant БД as [База Данных]

    Пользователь ->> Клиент: Запрос данных
    activate Клиент
    Клиент ->> Сервер: GET /api/data
    activate Сервер
    Сервер ->> БД: SELECT * FROM table
    activate БД
    БД -->> Сервер: Результат
    deactivate БД
    Сервер -->> Клиент: JSON Ответ (200 OK)
    deactivate Сервер
    Клиент -->> Пользователь: Отображение интерфейса
    deactivate Клиент
```

```mermaid
gantt
```

### Граф зависимостей

```mermaid
flowchart TD
    %% Основные уровни приложения
    App[Приложение / API] --> Auth[Модуль Авторизации]
    App --> Users[Модуль Пользователей]
    App --> Billing[Модуль Оплаты]

    %% Внутренние зависимости модулей
    Auth --> DB[(База Данных)]
    Auth --> Cache[(Redis Кэш)]

    Users --> DB

    Billing --> DB
    Billing --> Stripe[Stripe API / Внешний сервис]

    %% Инфраструктурные зависимости
    DB --> AWS[Облачный хостинг AWS]
    Cache --> AWS

    %% Стилизация зависимостей
    style App fill:#f9f,stroke:#333,stroke-width:2px
    style Stripe fill:#bbf,stroke:#333,stroke-dasharray: 5 5
    style AWS fill:#ddd,stroke:#999

```
